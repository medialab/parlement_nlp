# Tranining

```bash
usage: train.py [-h] [--start-trial-index START_TRIAL_INDEX] [--batch-size BATCH_SIZE] [--eval-steps EVAL_STEPS] hyperparams

positional arguments:
  hyperparams           Path to hyperparameters CSV file.

options:
  -h, --help            show this help message and exit
  --start-trial-index START_TRIAL_INDEX
                        Trial index to start from. Default to 0.
  --batch-size BATCH_SIZE
                        Batch size of training.
  --eval-steps EVAL_STEPS
                        Eval save steps.
```
