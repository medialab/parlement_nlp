# Parlement NLP

Dépôt du projet Parlement NLP visant à entraîner un modèle de d'embedding sensible à l'opinion (_stance aware_) en fine-tunant un modèle d'embedding sur un corpus de débats parlementaires.

Le modèle est disponible [sur Hugging Face](https://huggingface.co/datasets/medialab-sciencespo/QwAn), ainsi que les [jeux de données utilisées](https://huggingface.co/datasets/medialab-sciencespo/QwAn-dataset).
